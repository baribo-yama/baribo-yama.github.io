# こんにちは

ポートフォリオサイトを新しくデザインし直しました。

## デザイン方針

- さるわかのようなシンプルさ
- 淡いオレンジをアクセントカラーに

## 技術スタック

このサイトは以下の技術で構築されています：

- **フロントエンド**: React 18 + TypeScript
- **スタイリング**: Tailwind CSS
- **ビルド**: Vite
- **ルーティング**: React Router
- **記事管理**: Markdown + frontmatter
- **ホスティング**: GitHub Pages

## 工夫ポイント
- 内容の追加を行いやすいように各項目をjsonで管理
- 個人的すぎる技術的なこと、参加レポートなどを書くブログ機能

## 改善点
- なんとなくreactを使ったけど静的すぎるし動きも少ないのでAstroに乗り換える
