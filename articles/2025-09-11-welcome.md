# ようこそ

このポートフォリオサイトを新しくデザインし直しました。

## デザイン方針

- Notionのようなシンプルさ
- 白基調で装飾を最小限に
- 情報設計を重視

## 技術スタック

このサイトは以下の技術で構築されています：

- **フロントエンド**: React 18 + TypeScript
- **スタイリング**: Tailwind CSS
- **ビルド**: Vite
- **ルーティング**: React Router
- **記事管理**: Markdown + frontmatter
- **ホスティング**: GitHub Pages

## バックエンド視点の設計

単なるポートフォリオサイトではなく、バックエンドエンジニア志望者として以下の設計判断を言語化できるようにしました：

- **記事データはビルド時に静的JSON化**: 実行時パースの負荷を避け、常に完成された静的アセットを配信
- **Markdown + Gitでの記事管理**: DBレスな構成でバージョン管理を実現
- **GitHub Pages + GitHub Actions**: CI/CDパイプラインの自動化

今後、このサイト自体がバックエンド視点の設計思想を示すポートフォリオ作品として機能していきます。
