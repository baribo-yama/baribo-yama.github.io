# design.md

このファイルはポートフォリオサイトのデザインシステムを定義する。
実装時はこの内容を正として、感覚的な色・余白の指定を避ける。

## 1. デザインコンセプト

- **Notion的なシンプルさ**: 装飾よりも情報の構造そのもので魅せる
- **白基調**: 背景は白〜オフホワイト、アクセントカラーは最小限に絞る
- **AIっぽいグラデーションを使わない**: 単色のフラットな配色のみ。グラデーション、
  ネオン、グロー効果、派手なアニメーションは禁止
- **派手にしない**: モーション・アニメーションは「気づく程度」に留める(fadeやtranslateの
  微小な遷移のみ。バウンドや過剰なイージングは使わない)
- **機能はシンプルに**: 装飾コンポーネントを増やさず、情報設計で差をつける

## 2. カラーパレット

| 用途 | Tailwind推奨 | HEX | 備考 |
|---|---|---|---|
| 背景(base) | `bg-white` | #FFFFFF | メイン背景 |
| 背景(sub) | `bg-gray-50` | #FAFAFA | セクション区切り用の微差背景 |
| テキスト(主) | `text-gray-900` | #1A1A1A | 本文・見出し |
| テキスト(副) | `text-gray-500` | #6B7280 | 補足・日付・キャプション |
| 罫線 | `border-gray-200` | #E5E7EB | セクション区切り線、カード枠 |
| アクセント | `text-gray-900` + 下線 | #1A1A1A | リンクやアクセントは彩度を上げず、太字/下線で表現 |
| ワンポイント(任意) | 単色ブルーまたはグリーン系1色のみ | 例: #2563EB | ボタンやタグなど「1箇所だけ」に使う。複数色を混在させない |

原則: **色数を増やさない**。強調は「色」ではなく「太さ・余白・罫線」で行う(Notionの思想)。

## 3. タイポグラフィ

| 要素 | フォントサイズ(Tailwind) | Weight | 用途 |
|---|---|---|---|
| ページタイトル(H1) | `text-4xl` (36px) | `font-bold` | AboutMe名前など |
| セクション見出し(H2) | `text-2xl` (24px) | `font-semibold` | Works/History/Skills/Contactの見出し |
| 記事タイトル(H1) | `text-3xl` | `font-bold` | ブログ記事詳細 |
| 本文 | `text-base` (16px) | `font-normal` | 行間 `leading-relaxed` |
| 補足テキスト | `text-sm` (14px) | `font-normal text-gray-500` | 日付・タグ |

- フォントファミリーは system-ui ベース(`font-sans`)。日本語は游ゴシック/Noto Sans JP相当を
  フォールバックに含める。装飾フォントは使わない。

## 4. レイアウト・余白

- コンテンツ最大幅: `max-w-3xl`(記事・About等の読み物系) / `max-w-5xl`(Works一覧などグリッド系)
- セクション間の縦余白: `py-16`〜`py-20`(セクションごとに空気を持たせる)
- 左右パディング: `px-4 md:px-8`
- カード内パディング: `p-6`
- 罫線での区切りを基本とし、背景色の切り替えは最小限(`bg-gray-50`を1段のみ使う)

## 5. コンポーネント設計

### 5.1 Header(固定ヘッダー)
- `fixed top-0 w-full z-50 bg-white/90 backdrop-blur border-b border-gray-200`
- 高さ: `h-14`
- 左: ロゴ or 名前(テキストのみ、アイコン不要)
- 右: `Home` / `Blog` の2リンクのみ、`text-sm font-medium`
- スクロール時も背景を保つため半透明+blurで下のコンテンツと区別する(派手なシャドウは使わない)

### 5.2 AboutMe
- ヘッダー直下、ページ最上部
- 名前(H1) + 一言紹介文(1〜2行) + 簡単なリンク(GitHub, Xなど、テキストリンクのみ)
- 顔写真やアイコンを使う場合は角丸(`rounded-full`)、影は最小限

### 5.3 Works(成果物カード)
- グリッド表示(`grid grid-cols-1 md:grid-cols-2 gap-6`)
- カードに強い影(`shadow-lg`等)は使わない。`border border-gray-200`で十分
- **要約表示(デフォルト)**: タイトル + 概要(1〜2行) + 使用技術タグ(`bg-gray-100`程度) + リンクアイコン(GitHub/デプロイURL)
- カード下部に「もっと見る」テキストリンクを設置。クリックで**同じカード内をアコーディオン展開**
  し、以下を追加表示する(別ページ・モーダルには遷移しない)
  - 制作の背景
  - 担当箇所
- 展開/収納の状態はカードごとに独立(1枚を開いても他のカードには影響しない)
- 展開アイコンは`v`/`^`程度のシンプルなシェブロンのみ(装飾的なアイコンは避ける)

### 5.4 History(縦タイムライン)
- 左側に縦線(`border-l border-gray-300`)、各項目を`pl-6`でインデント
- 各項目: 期間(text-sm text-gray-500) + 見出し + 説明文のみ(テキストのみ。画像・リンク・アンカーは持たせない)
- 時系列は上から新しい順 or 古い順で統一(どちらでもよいが混在させない)

### 5.5 Skills(技術一覧)
- タグ形式(`inline-block border border-gray-300 rounded px-3 py-1 text-sm`)
- カテゴリ分け(言語 / フレームワーク / インフラ 等)を見出しで区切る
- アイコン使用は任意だが、使う場合は単色アイコンに統一(カラフルなロゴ乱立を避ける)

### 5.6 Intern(Contactの直上)
- カード形式、1社1カード。グリッドまたは縦並び(Worksほど情報量が多くないため縦並びでも可)
- カード内の要素順序は固定: **画像(企業ロゴ等) → 社名 → インターン内容(簡潔な説明文、1〜2行)**
- Worksのような展開機能は不要。1カードで完結させる
- 画像サイズは統一(例: `w-16 h-16`程度の正方形、角丸`rounded`)。カラフルなロゴが並ぶ場合は
  枠線(`border border-gray-200`)で統一感を出す

### 5.7 Contact
- シンプルなテキストリンク(メール、GitHub、Xなど)を縦または横に並べる
- フォーム実装は行わない(mailtoリンク or 外部リンクで十分)

### 5.8 Blog一覧カード
- タイトル + 日付 + タグ + 概要抜粋、罫線区切りのリスト形式(Notionのデータベース一覧のような見た目)
- サムネイル画像は必須にしない

### 5.9 記事詳細(Markdownレンダリング)
- 見出し・段落・リスト・コードブロックの装飾はQiita/Zennに近いシンプルな配色
- コードブロック背景: `bg-gray-900 text-gray-100`(ここだけはダーク配色を許容し、可読性を優先)
- インラインコード: `bg-gray-100 text-gray-800 rounded px-1`

## 6. モーション

- ページ遷移・要素出現は `transition-opacity duration-200` 程度に留める
- ホバー時のボタン/リンクは `hover:opacity-70` 程度のシンプルな変化のみ
- スクロールトリガーの派手な演出(パララックス等)は使わない
